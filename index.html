이 방침은 성경암송 Android 앱(패키지 이름: com.channelofgospel.scripturememory)의 정보 처리에 관한 안내입니다.

1. 앱에서 처리하는 정보

앱에는 회원가입이나 로그인 기능이 없습니다. 운영자가 관리하는 서버로 이름, 이메일 주소, 연락처, 위치 또는 암송 내용을 자동 수집하는 기능을 제공하지 않습니다. 광고, 사용자 행동 분석 및 자동 오류 보고를 위한 SDK를 사용하지 않습니다.

복습으로 선택한 구절, 사용자가 작성한 OYO 카드, 글자 크기와 문단 정렬 등 읽기 설정, 음성 사용 여부와 선택한 음성, 다운로드한 음성 파일 및 다운로드 관리 정보는 앱 기능을 제공하기 위해 사용자 기기의 앱 전용 저장 공간에 저장됩니다. 이 정보는 운영자에게 전송되지 않습니다.

2. 음성 파일 다운로드 및 외부 서비스

음성 파일은 사용자가 다운로드를 선택했을 때 GitHub 및 해당 파일 배포 서버에서 HTTPS 연결로 받습니다. 이 과정에서 파일 제공에 필요한 IP 주소, 요청 시각 및 요청한 파일 주소 등 통신 정보가 해당 서비스에 전달되거나 처리될 수 있습니다. 운영자는 다운로드 요청에 OYO 카드 내용이나 복습 선택 정보를 포함하지 않습니다. 다운로드한 음성은 이후 기기에서 재생합니다.

GitHub의 정보 처리에 관한 자세한 내용은 GitHub 개인정보처리방침을 확인할 수 있습니다.

3. Android 백업 및 기기 이전

앱은 Android 시스템의 백업 기능을 허용합니다. 기기와 계정의 백업 설정에 따라 설정, 복습 선택 및 OYO 카드 등 앱 데이터가 Google 또는 기기 제조업체의 백업·기기 이전 기능으로 복사되거나 복원될 수 있습니다. 다운로드 음성 파일은 앱의 백업 제외 저장 공간에 저장됩니다. 시스템 백업의 처리와 삭제는 해당 서비스 제공자의 정책 및 사용자 설정에 따릅니다. 운영자는 시스템 백업에 접근하지 않습니다.

4. 문의 시 제공하는 정보

사용자가 이메일로 문의하면 이메일 주소와 문의 내용, 사용자가 첨부한 자료를 문의 확인 및 답변에 사용합니다. 문의에 필요하지 않은 민감한 정보는 보내지 않도록 해 주세요. 문의 정보는 처리에 필요한 기간 동안 보관하고, 목적을 달성하여 더 이상 필요하지 않으면 삭제합니다. 법령에 따른 보관 의무가 있는 경우 해당 범위와 기간을 따릅니다.

5. 보관 및 삭제

기기에 저장된 데이터는 사용자가 삭제하거나 Android 설정에서 앱 저장 데이터 삭제 또는 앱 제거를 할 때까지 보관됩니다. OYO 카드는 앱에서 삭제할 수 있고, 다운로드한 음성은 음성 다운로드 관리 기능에서 삭제할 수 있습니다. 앱 데이터 삭제 시 OYO 카드와 복습 선택, 설정 등도 함께 삭제되므로 주의해 주세요. 시스템 백업 사본은 별도로 관리되며, 이후 복원 시 데이터가 다시 나타날 수 있습니다.

6. 정보 보호 및 제3자 제공

앱은 사용자 데이터를 앱 전용 저장 공간에 보관하고 음성 다운로드에는 HTTPS를 사용합니다. 운영자는 사용자 데이터를 판매하거나 광고 목적으로 제공하지 않습니다. 음성 다운로드와 시스템 백업에 따른 외부 서비스 처리는 위 내용을 참고해 주세요.

7. 아동 및 이용자의 문의

운영자는 아동을 포함한 이용자의 개인정보를 앱에서 자동 수집하는 기능을 제공하지 않습니다. 개인정보 처리에 관한 확인, 삭제 요청 또는 우려 사항이 있으면 위 문의 이메일로 연락할 수 있습니다. 기기에만 저장된 데이터는 운영자가 원격으로 열람하거나 삭제할 수 없습니다.

8. 방침 변경

앱 기능 또는 정보 처리 방식이 변경되면 이 페이지의 개인정보처리방침과 시행일을 갱신합니다. 중요한 변경은 앱 또는 배포 안내를 통해 알립니다.
